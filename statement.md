* Problem Statement
Bank customers frequently require assistance with common services such as checking account balances, reporting lost or stolen debit cards,
obtaining loan information, resetting internet banking passwords, and contacting customer care.
Handling these requests manually can be time-consuming, especially when customers need help with simple and repetitive tasks.

The system provides users with a menu-driven interface where they can select a language and choose different banking support options.
The project demonstrates how basic programming concepts can be used to simulate a customer support system.

* Scope of the Project

The project focuses on developing a basic customer care bank service that provides a number of options like 
language selection in which a person can select from the three options like English, Other Language as well as he/she can also exit.
After that there are various sub options related to banking.

* Target Users

The primary target users of this project are:

Students learning Python programming.
Beginners interested in coding and it's applications.
Students studying Computer Science and Engineering.
Teachers or instructors demonstrating basic programming concepts.

* High-Level Features

1. Language Selection Option: We can select English Language as well as Other Language, although currently other languages are not available.
2. Main Menus various options like:
=>  Account Balance
=>  Block a Lost or Stolen Debit Card
=>  Loan
=>  Internet Banking Support
=>  Speak with Customer Care Executive
=>  Go Back to the Language selection
3. Invalid Input Handling: Displays appropriate messages when an invalid option is entered.
4. Exit Option: Allows users to terminate the support system.
